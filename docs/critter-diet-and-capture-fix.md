# 颚鱼食谱与幼体捕捉修复（critter20）

2026-11-02；ONI 744825；构建 `fix-20261102-critter20`。

## 颚鱼增加藻蝌蚪食谱

用户所说的鳄鱼、枣蝌蚪，对应当前游戏简体中文翻译的颚鱼（Jawbo，`PrehistoricPacu`）和藻蝌蚪（Kelpole，`SeaFairy`）。本地游戏 `BasePrehistoricPacuConfig.CreatePrefab` 同时负责成年和幼年颚鱼。

在共用工厂完成后，保留已有每条 Diet.Info，追加 `SeaFairy` 的 `EatPrey` 活体捕食条目；饥饿监视器和固体摄食监视器使用同一份新 Diet，构造函数重建食物及猎物缓存。原版矿甲龟的藻蝌蚪参数为每千克 80,000 卡，产物换算系数 `SeaTurtleTuning.POOP_KG_PER_CYCLE / 2 / 5`；颚鱼采用这些参数，产物保持铁锈。已有帕库鱼、变种帕库鱼、鱼肉、熟鱼等条目及熟鱼效果不改，颚鱼原代谢、胃容量和排泄阈值不改。发现已有藻蝌蚪条目时不重复追加。

使用原版同房间寻找猎物和寻路流程，不增加全地图扫描、额外模拟定时器或强制捕杀。猎物选择沿用游戏规则，没有新增藻蝌蚪优先级。配置在预制体创建时应用，覆盖新游戏和重新加载存档中的颚鱼，不重写存档。

## 幼体被无条件捕捉的原因与修复

旧 `EggIncubator.StoreBaby` 后置补丁及 `OnSpawn` 看门狗，在弹出幼体后直接调用 `Baggable.SetWrangled` 并加 Deliverable，完全没有检查取出点。这会让刚孵化的飞行幼体也直接进入袋装状态。

现在保留自动出雏，仅处理仍为该孵化器 Occupant 的非蛋实体；清掉孵化器存储期间的临时袋装状态和可搬运标记，恢复动物绘制层并唤醒大脑。保留自动换蛋订单。地上已经被旧版打包的动物无法可靠区分人工捕捉与错误打包，本版不批量解袋；这些动物需通过原有放生操作处理。

取出点旧代码还会绕过原版房间及寻路限制、扫描同星球动物，并在 12 秒后强制传送打包。现删除这些路径，沿用原版房间、幼体开关、数量、筛选、优先级和可达性规则，必须经过原版 MoveTo 到站再完成捕捉。结算在独立模拟回调执行，避免在动物进入状态的回调内部停止当前任务；手动捕捉保留原版工作流程。到站后仅保留站点定义自身的出料偏移，不远程传送动物，不强制覆盖可达性状态。新增运行时组件不写入存档。
