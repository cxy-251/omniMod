## 5xHarvest.SC2Mod  （已存在，Gemini 做的，数值已核对）
Extension mod：所有矿点/气矿采集量 ×5（矿 5→25，富矿 7→35，气 4→20，含 Purifier/
BattleStation/750/各族变体）。依赖 `Void (Mod)` + `VoidMulti (Mod)`（LotV 多人标准依赖）。

用法（在正常客户端里）：
  创建自定义游戏 → 选图 → 右侧「额外 Mod / Mods」加上 5xHarvest → 加一个 电脑(残酷) → 开打

游戏目录里的正本在 `/home/deck/Games/StarCraft II/Mods/5xHarvest.SC2Mod`，
也已拷进 Wine 前缀的 `Documents/StarCraft II/Mods/`。
